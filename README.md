

# 📚 스터디룸 예약 플랫폼[ROOM:IT] 📚
![BUMBLEBEE_ROOMIT](https://github.com/user-attachments/assets/1e5ef171-c9d0-48e9-9960-7945c5be25dc)

## ✨ 프로젝트 소개
___
> Room:it은 기존 예약 시스템에 문제점을 파악하여 사용자에게 보다 효율적이고 
> 직관적인 서비스를 제공하는 스터디룸 예약 및 관리 플랫폼 입니다
